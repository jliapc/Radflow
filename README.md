# RadFlow
Plataforma para centralizar a comunicação e o compartilhamento de exames entre clínicas de radiologia odontológica e dentistas.
## Sobre o projeto
O RadFlow surgiu a partir da observação de um problema real na rotina de clínicas de radiologia odontológica: a comunicação e o envio de exames podem acontecer por diferentes canais, como WhatsApp, e-mail e outros sistemas.
A proposta do projeto é centralizar esse fluxo em uma plataforma, facilitando o acesso aos exames e a comunicação entre os profissionais envolvidos.
## Objetivo
Desenvolver uma solução digital que facilite o fluxo de exames entre clínicas de radiologia odontológica e dentistas.
